# 🌱 Soil-Based Crop Advisor

A rule-based web application that recommends suitable crops based on soil and climate conditions.

## 📌 About the Project

Soil-Based Crop Advisor is a frontend web application designed to help users identify crops that may be suitable for their soil and local climate conditions.

Users can enter soil nutrient values such as Nitrogen (N), Phosphorus (P), Potassium (K), soil pH, Magnesium and Sulfur, along with rainfall and temperature values.

The application compares these values with predefined reference ranges and generates a crop suitability score.

## ✨ Features

- 🌱 Soil nutrient input
- 🧪 Soil pH analysis
- 🌧️ Rainfall consideration

## ⚙️ How It Works

1. Enter the soil test values.
2. Select the required growing season.
3. Click **"Read the soil"**.
4. The application compares the entered values with predefined crop requirements.
5. Crops are ranked according to their suitability score.

## 📊 Scoring

The application uses a rule-based scoring system.

The displayed percentage represents how closely the entered soil and climate values match the predefined reference ranges for each crop.

**It is a suitability score, not a prediction accuracy or guarantee of crop yield.**
